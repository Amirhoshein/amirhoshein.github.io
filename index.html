چطور وصل بشم؟

چهار قدم تا شروع بازی:

  1. ماینکرفت رو باز کن و روی Multiplayer بزن.
  2. روی Add Server بزن و آدرس hshmc.ir رو بذار، بعد Join Server.
  3. اولین بار باید ثبت‌نام کنی: /register pass passAgain
  4. دفعه‌های بعد برای ورود: /login pass

به‌جای pass رمز دلخواهت رو بنویس و passAgain همون رمز رو دوباره تکرار کن. رمزت رو فراموش نکن!
